# Lit Review Construct

Lit Review Construct is a local-first, AI-assisted literature review construction toolkit for researchers.

It helps researchers discover, understand, organize, and construct the literature behind a research project while keeping the researcher responsible for scholarly judgment, source verification, authorship, and final prose.

## Initial scope

- Windows-first
- Codex Desktop and OpenCode
- Narrative literature-review construction
- Local project state in `.litreview/`
- Seed literature and external paper folders
- Research Intent → Research Landscape → Evidence Map → Research Direction → Literature Review Blueprint
- AI-use statement based on actual recorded activity

The toolkit does **not** generate a complete final literature review for direct submission.
